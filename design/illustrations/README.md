# Illustrations

The 23 scenes (light and dark) are generated by `packages/brand-assets/scripts/illustrations.mjs`
from shared primitives in `svg-kit.mjs`. Style rules: [ILLUSTRATION_GUIDELINES.md](../../docs/ILLUSTRATION_GUIDELINES.md).
Preview: `pnpm docs:build`, then open `packages/documentation/dist/illustrations.html`, or see
`references/renders/specimen-illustrations-*.webp`.

Adding a scene:
1. Write a brief here (`illustrations-<scene>-brief.md`): purpose, where it appears, the one accent
   colour, what the violet spark marks.
2. Sketch on the 240×180 artboard with the role palette.
3. Implement it as a scene in `illustrations.mjs`, run `pnpm assets:generate && pnpm assets:validate`
   and `pnpm flutter:sync-assets`.
